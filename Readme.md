🧹 Garbage Collector CLI (C#)

A simple command-line tool built in C# that scans a specified directory and removes unwanted or unnecessary files. This project acts as a lightweight "garbage collector" for your file system, helping you keep directories clean and organized.

🚀 Features
📂 Scan any given directory
🗑️ Delete unwanted files automatically
⚡ Fast and lightweight CLI tool
🔧 Easy to configure and extend
🧼 Helps maintain clean file structures
🛠️ Technologies
C#
.NET (CLI Application)
